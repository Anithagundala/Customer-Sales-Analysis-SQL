# Customer & Sales Analysis using SQL

## Project Overview
This project analyzes customer and sales data using SQL to identify business trends and insights.

## Objectives
- Analyze overall sales performance
- Identify top customers
- Find best-performing products
- Analyze sales by category and region
- Generate business insights

## SQL Skills Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- Aggregate Functions (SUM, AVG)
- Filtering and Sorting

## Files
- sales_data.csv — sample sales dataset
- sales_analysis.sql — SQL analysis queries

## Key Insights
- Identified top-performing customers based on total sales.
- Analyzed product and category-wise sales performance.
- Compared sales performance across regions.
- Calculated total sales, average order value, and total quantity sold.

## Tools
- SQL
- GitHub

## Note
The dataset is a small practice dataset created for learning and portfolio purposes.
